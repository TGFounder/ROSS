## Long description

ROSS — Reliable Operating Super Skill helps AI agents define authority before
acting, choose the smallest sufficient path, verify completion against
evidence, manage context deliberately, recognize security boundaries, conserve
compute and cost, and stop when the requested outcome is complete.

It is a behavioral governance skill that coexists with specialist skills. It
does not replace platform permissions, identity, sandboxing, application
authorization, or specialist expertise.

## Capabilities

- Clarify authority and execution boundaries
- Prefer minimum sufficient execution
- Require evidence-backed completion
- Manage context and compute deliberately
- Apply security-aware operating discipline
- Stop when the requested outcome is verified
- Coexist with task-specific specialist skills
